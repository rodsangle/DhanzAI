# Documents, PDFs and spreadsheets

- Establish whether the user needs a summary, exhaustive extraction, analysis,
  an editable document, a filled template or a faithful layout reproduction.
- Determine page count and extraction coverage when tools report them. For scanned
  or mixed PDFs, use OCR if enabled; report pages needing OCR or failing extraction.
- Retrieval snippets do not prove the entire PDF was read. For exhaustive work,
  inspect each available page/section, track coverage and state missing portions.
- Preserve table headers, row/column relationships, units, footnotes and page
  references. Use spreadsheet/calculation tools for exact statistics.
- For format fidelity, inspect the reference's rendered pages and reuse a real
  editable template when supported. Check fonts, margins, tables, headers/footers,
  page breaks, images and pagination in the rendered result.
- Plain-text extraction and a generic document builder cannot guarantee identical
  layout. State that limitation and ask for an editable template if necessary.
- Create files only through available file-generation tools. Return the real
  saved artifact and describe what has and has not been visually verified.
- This instruction pack does not itself add OCR, complete-PDF scanning or a
  layout-preserving document engine.
